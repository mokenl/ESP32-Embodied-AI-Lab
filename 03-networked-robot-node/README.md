# 03 · 网络化机器人节点（Networked Robot Node）

## 目标

加入**执行器**与**网络**：让节点既能动，又能被远程控制、能把自己的状态回传上来。

这一模块把前两个模块的「感知」变成「行动」，是从传感器走向机器人的关键一步。

## 硬件清单

| 器件 | 型号建议 | 作用 |
| --- | --- | --- |
| 主控 | ESP32 | 主控与联网 |
| 电机驱动 | TB6612FNG / L298N | 直流电机驱动 |
| 电机 | 带编码器直流减速电机 ×2 | 底盘驱动与测速 |
| 舵机 | SG90 / MG996R | 云台或夹爪 |
| 电源 | 18650 ×2 + 降压模块 | 电机与主控分离供电 |
| 底盘 | 两轮差速 / 四轮麦轮 | 运动平台 |

## 技术栈

- 通信：Wi-Fi、MQTT、WebSocket、ESP-NOW（节点间直连）
- 控制：PWM 调速、编码器测速、PID 闭环、差速运动学
- 系统：FreeRTOS 多任务、看门狗、OTA 升级
- 上位机：网页控制面板 / Python 客户端 / 手机端

## 目录规划

```text
03-networked-robot-node
├── firmware/        # ESP32 机器人固件
├── control/         # 上位机控制程序与网页面板
├── docs/            # 通信协议、控制指令表、调参记录
└── hardware/        # 车体结构、接线、电源方案
```

## 通信协议草案

| 方向 | 主题 / 指令 | 载荷 |
| --- | --- | --- |
| 下行 | `robot/cmd` | 线速度、角速度、舵机角度 |
| 上行 | `robot/state` | 电池电压、编码器计数、当前速度 |
| 上行 | `robot/event` | 碰撞、堵转、超时告警 |
