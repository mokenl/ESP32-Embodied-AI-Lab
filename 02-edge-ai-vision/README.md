# 02 · 边缘 AI 视觉（Edge AI Vision）

## 目标

把视觉推理放到 MCU 边缘侧：ESP32-S3 采集图像，本地跑轻量神经网络，只把「结论」而不是原始图像发出去。

关注点是**能不能在几百 KB 的 RAM 里跑起推理**，以及功耗、帧率与精度之间的取舍。

## 硬件清单

| 器件 | 型号建议 | 作用 |
| --- | --- | --- |
| 主控 | ESP32-S3（建议带 8MB PSRAM） | 图像处理与推理 |
| 摄像头 | OV2640 / OV5640 | 图像采集 |
| 显示（可选） | ST7789 / ILI9341 屏幕 | 本地预览与调试 |
| 补光 | 白光 LED + 三极管驱动 | 暗光环境 |
| 存储（可选） | microSD 卡模块 | 数据集采集 |

## 技术栈

- 图像链路：DVP 摄像头驱动、JPEG 编解码、双缓冲
- 推理框架：ESP-DL、TFLite Micro、ESP-WHO
- 模型工程：量化（INT8）、模型剪枝、算子内存复用
- 输出方式：MQTT / HTTP / 串口输出结构化结果

## 实验方向

1. 图像采集与显示（先把画面跑起来）
2. 人脸检测（ESP-WHO 现成模型跑通）
3. 自定义分类：色块 / 手势 / 物体（自己采数据训练）
4. 与 01 模块联动：视觉结果 + 环境数据的融合上报
