# 01 · 智能传感器节点（Smart Sensor Node）

## 目标

用 ESP32 稳定采集物理世界的数据，在节点本地完成滤波、校准与打包，再通过串口 / 网络可靠上报。

这一模块是整个实验室的「感知底座」，后续 02/03/04 都建立在这条数据链路之上。

## 硬件清单

| 器件 | 型号建议 | 作用 |
| --- | --- | --- |
| 主控 | ESP32 DevKitC / ESP32-C3 | 采集与主控 |
| 温湿度气压 | BME280 | 环境感知 |
| 惯性测量 | MPU6050 / MPU9250 | 姿态与运动 |
| 光照 | BH1750 | 环境光强 |
| 模拟量 | 电位器 / 光敏电阻 / NTC | ADC 采集练习 |
| 显示（可选） | SSD1306 OLED | 本地显示 |

## 技术栈

- 总线与外设：I2C、SPI、UART、ADC、OneWire
- 固件框架：Arduino（入门）/ ESP-IDF + FreeRTOS（进阶）
- 数据处理：滑动平均、中值滤波、互补滤波 / 卡尔曼滤波
- 可靠性：看门狗、断线重连、数据校验（CRC）
- 低功耗：Light Sleep / Deep Sleep、定时唤醒
